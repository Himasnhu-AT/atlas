A priority queue provides access to the element with the highest priority (or lowest numerical key value in a min-heap) in $O(1)$ time, while supporting insertion and deletion in logarithmic time. In C++, `std::priority_queue` implements a max-heap backed by a dynamic array (`std::vector`).

Rather than storing explicit tree nodes with left and right child pointers on the heap, a binary heap maps a complete binary tree directly into a flat contiguous array.

## Complete binary trees in contiguous memory

A **complete binary tree** is a binary tree where every level is completely filled except possibly the last level, which is filled from left to right. This structural invariant allows storing tree nodes in level-order inside an array without gaps.

For any element at zero-based array index $i$:

```
Parent index:       parent(i) = (i - 1) // 2
Left child index:   left(i)   = 2 * i + 1
Right child index:  right(i)  = 2 * i + 2
```

```
Tree structure:
             [0: 10]
            /       \
       [1: 15]     [2: 20]
       /     \     /
   [3: 30] [4: 25] [5: 40]

Array representation:
Index:   0    1    2    3    4    5
Value: [ 10 | 15 | 20 | 30 | 25 | 40 ]
```

Contiguous storage eliminates the 16 bytes of pointer overhead per node required by linked tree structures and guarantees optimal CPU cache spatial locality during sequential scans.

## The heap property and sift-up insertion

In a **min-heap**, every parent node satisfies the invariant that its key is less than or equal to the keys of its children:

```
key(parent(i)) <= key(i)  for all i > 0
```

### Insertion (Sift-up)

When inserting a new element:
1. Append the element to the end of the array at index $n$ (preserving the complete tree shape).
2. Compare the element with its parent at index `(n - 1) // 2`.
3. If the element is smaller than its parent, swap them.
4. Repeat step 2 moving upward toward the root until the heap property is satisfied or the element reaches the root (index 0).

```
Insert value 12 into heap:
1. Append 12 at index 6: [10, 15, 20, 30, 25, 40, 12]
2. Parent of index 6 is index 2 (value 20). 12 < 20 -> Swap!
   Array: [10, 15, 12, 30, 25, 40, 20]
3. Parent of index 2 is index 0 (value 10). 12 >= 10 -> Stop!
```

Since the height of a complete binary tree containing $n$ elements is $\lfloor \log_2 n \rfloor$, sift-up executes at most $O(\log n)$ swaps.

## Root extraction and sift-down

To extract the minimum element:
1. The minimum element resides at root index 0.
2. Move the last element in the array to index 0, and remove the last slot (reducing array size by 1).
3. **Sift-down**: Compare the node at index $i$ with its left child ($2i+1$) and right child ($2i+2$).
4. Identify the smallest child. If that child is smaller than the parent, swap them.
5. Repeat downward until the node is smaller than both children or reaches a leaf position.

Sift-down restores the min-heap invariant in $O(\log n)$ time.

## Linear-time heapify algorithm

Constructing a heap from an arbitrary array of $n$ elements can be performed in two ways:

1. **Repeated insertion**: Inserting $n$ elements sequentially with sift-up takes $O(n \log n)$ time.
2. **Bottom-up heapify (Floyd's algorithm)**: Sifting down from the lowest internal nodes runs in $O(n)$ time.

Leaf nodes have no children and already satisfy the heap property trivially. The last non-leaf node in an array of size $n$ is located at index `(n - 2) // 2`.

Floyd's algorithm iterates backwards from index `(n - 2) // 2` down to 0, running `sift_down` at each index:

```python
def heapify(array):
    n = len(array)
    for i in range((n - 2) // 2, -1, -1):
        sift_down(array, i, n)
```

The mathematical proof of $O(n)$ complexity relies on node distribution by tree height:
- There are $\lceil n / 2 \rceil$ leaves (height 0, 0 swaps).
- $\lceil n / 4 \rceil$ nodes at height 1 (at most 1 swap).
- $\lceil n / 8 \rceil$ nodes at height 2 (at most 2 swaps).
- In general, $n / 2^{h+1}$ nodes at height $h$.

The total operations sum to:

$$
\sum_{h=0}^{\lfloor \log_2 n \rfloor} \frac{n}{2^{h+1}} \cdot h = \frac{n}{2} \sum_{h=0}^{\infty} \frac{h}{2^h} = \frac{n}{2} \cdot 2 = n
$$

The infinite series $\sum_{h=0}^\infty h / 2^h$ converges to 2. Consequently, bottom-up heapification completes in $O(n)$ time.
