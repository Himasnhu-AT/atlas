A vectorized backtest applies operations across entire Pandas series simultaneously. While fast to compute, vectorized backtesting introduces three structural flaws:

1. **Lookahead leakage**: Accidental alignment of signals generated at timestamp $t$ with prices realized at timestamp $t$ rather than timestamp $t+1$.
2. **Execution blindness**: Assuming limit orders fill immediately at bar close without modeling queue position or traded volume.
3. **Unrealistic rebalancing**: Assuming entire multi-asset portfolios rebalance instantaneously at zero transaction cost without tracking cash, collateral, or partial fills.

## The event-driven architecture

An **event-driven backtester** mirrors live trading infrastructure. The system processes discrete, timestamped message objects through a central queue:

```
[ MarketEvent ] ---> Strategy Module
                            |
                     [ SignalEvent ] ---> Portfolio / Risk Manager
                                                |
                                         [ OrderEvent ] ---> Execution Handler
                                                                   |
                                                            [ FillEvent ] ---> Portfolio Ledger
```

Each event triggers deterministic state updates:

* **MarketEvent**: Contains incoming price and volume updates (ticks or bars) for a specific symbol.
* **SignalEvent**: Generated by a strategy indicating a target portfolio weight or direction.
* **OrderEvent**: Generated by the portfolio/risk manager converting target weights into discrete orders (symbol, side, quantity).
* **FillEvent**: Generated by the execution handler simulating exchange execution with slippage, commission, and fill price.

## Causal dispatching

In an event loop, no component accesses data from future timestamps. A signal generated on bar $t$ creates an order that can only be filled against market data arriving at timestamp $t+1$ or later.

This decoupling guarantees that strategy code written for the backtester runs without modification in a live execution environment.
