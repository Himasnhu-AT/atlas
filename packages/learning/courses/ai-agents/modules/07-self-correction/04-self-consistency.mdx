Self-consistency establishes confidence by sampling multiple independent reasoning paths for the same prompt and determining the majority consensus.

```python
answers = [model(question) for _ in range(5)]
final = most_common(answers)
```

The approach builds on the probabilistic nature of generation explored in [sampling](lesson:ai-llm-fundamentals.sampling). At temperatures above zero, each API call represents an independent sample from the model's output distribution.

## Evaluating consensus and variance

When a problem possesses a clear, deterministic answer, token probability distributions concentrate tightly, producing high agreement across independent samples. When reasoning is ambiguous or context is insufficient, candidate generations diverge.

The majority consensus across five samples achieves higher accuracy than an individual draw. Furthermore, the variance across samples provides a direct measure of uncertainty:

A single sample returns an answer without an associated confidence metric. Sampling five times produces both a candidate answer and an empirical distribution. Five identical outputs indicate strong convergence, whereas five conflicting answers signal ambiguity.

## Temperature selection

Sampling parameters directly determine verification utility:

Setting temperature to zero produces identical outputs across all samples, incurring 5x cost without generating additional information. Setting temperature too high introduces excessive randomness unrelated to problem difficulty.

Effective self-consistency uses moderate temperature settings (such as 0.5 to 0.7) to allow exploration across distinct reasoning paths while preserving focus on high-probability tokens.

## Normalization before counting

Computing the mode requires standardizing response representations before comparison.

Outputs like `"42"`, `"42."`, `"The answer is 42"`, and `" 42 "` convey the same semantic conclusion but fail exact string equality. A normalization step must trim whitespace, normalize casing, strip punctuation, and extract numeric entities prior to voting.

Normalization logic must balance flexibility against over-collapsing distinct meanings, similar to threshold tuning in [injection through a tool result](lesson:ai-agent-security.injection-through-a-tool-result).

## Interpreting sample distributions

The distribution of votes yields actionable operational signals:

**High consensus (5-0 or 4-1).** High confidence indicates the response can proceed without additional verification.

**Split distribution (3-2).** A divided vote indicates marginal confidence. The runtime can escalate the query, flag the response for human review, or run a targeted claim verification pass.

**High dispersion (all distinct answers).** Complete divergence indicates the query is underspecified, the context lacks necessary information, or the model capacity is insufficient for the reasoning depth required.

Suppressing a split vote and returning the slim majority as an authoritative answer discards the primary signal the method provides.

## Scope of applicability

Self-consistency applies effectively to tasks with discrete, comparable outcomes: classification tags, numeric values, boolean assertions, and structured entity extractions.

The method is unsuitable for long-form prose or open-ended generation, where distinct phrasing prevents direct majority voting. For long-form text, decomposing assertions into verifiable claims provides a more reliable approach.
